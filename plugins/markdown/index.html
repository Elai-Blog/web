基础篇 ​

  • Markdown 是一种轻量级标记语言，排版语法简洁，让人们更多地关注内容本身而非排版。
  • 它使用易读易写的纯文本格式编写文档，可与 HTML 混编，可导出 HTML、PDF 以及本身的 .md 格式的文件。
  • 因简洁、高效、易读、易写，Markdown 被大量使用。

标题 ​

  • 格式
markdown
# 一级标题

## 二级标题

### 三级标题

#### 四级标题

注意事项

  • 使用#在一行的最前面，并且#后面需要跟一个空格。
  • 最好只使用 3 级标题。
