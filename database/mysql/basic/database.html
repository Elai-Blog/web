数据库 ​

  • Database 是用来存储和管理数据的仓库。
  • 基本上一个项目对应一个database

基本操作 ​

查看数据库 ​

sql
SHOW DATABASES;

创建数据库 ​

sql
CREATE DATABASE IF NOT EXISTS database_name
    # 字符集
    CHARACTER SET utf8mb4
    # 排序规则
    COLLATE utf8mb4_unicode_ci;

删除数据库 ​

sql
DROP DATABASE IF EXISTS database_name;

字符集 ​

  • 定义字符的编码规则，决定如何将字符转换为二进制存储。
字符集是否推荐描述
utf8mb4是一个字符由4个字节组成，支持所有的字符，包括 emoji。
utf8否一个字符由3个字节组成。支持基本字符，不包含 emoji。

排序规则 ​

  • 基于字符集的排序 / 比较规则
排序规则是否推荐描述
utf8mb4_general_ci是通用排序，不区分大小写（ci = case insensitive），性能较好。
utf8mb4_unicode_ci否遵循 Unicode 标准排序，更准确但性能略低（推荐用于多语言场景）。
