查询数据 ​

  • 对表的数据进行查询、插入、更新、删除等操作。

插入数据 ​

  • 格式： INSERT INTO 表名 (字段1, 字段2, ...) VALUES (值1, 值2, ...)
sql
INSERT INTO `admin` (`name`, `password`, `phone`)
VALUES ('admin', '123456', '13800000000');

更新数据 ​

  • 格式： UPDATE 表名 SET 字段1=值1, 字段2=值2, ... WHERE 条件
sql
UPDATE `admin` SET `password`='newpassword' WHERE `name`='admin';

Insert Or Update ​

  • 格式： INSERT INTO 表名 (字段1, 字段2, ...) VALUES (值1, 值2, ...) ON DUPLICATE KEY UPDATE 字段1=值1, 字段2=值2, ...
sql
# 插入数据必须包含唯一键，如主键或唯一索引
# 下面`phone`设置了唯一索引,参考上一张表设计
# 若数据存在就更新，不存在就插入
INSERT INTO `admin` (`name`, `password`, `phone`,`created_at`)
VALUES
('admin1', '123456', '13800000000','2025-01-01')
ON DUPLICATE KEY UPDATE `name` = 'admin1',
`password` = 'newpassword',
`phone` = '13800000000';

删除数据 ​

  • 格式： DELETE FROM 表名 WHERE 条件
sql
DELETE FROM `admin` WHERE `name`='admin';

清空数据 ​

  • 格式： TRUNCATE TABLE 表名
sql
TRUNCATE TABLE `admin`;

查询数据 ​

查询所有字段 ​

  • 格式： SELECT * FROM 表名
sql
SELECT * FROM `admin`;

查询指定字段 ​

  • 格式： SELECT 字段1, 字段2, ... FROM 表名
sql
SELECT `name`, `email` FROM `admin`;

条件查询 ​

  • 格式： SELECT 字段1, 字段2, ... FROM 表名 WHERE 条件
sql
SELECT `name`, `email` FROM `admin` WHERE `name`='admin';

多条件查询 ​

  • 格式： SELECT 字段1, 字段2, ... FROM 表名 WHERE 条件1 AND/OR 条件2
  • 注意事项：OR 查询时，需要注意条件的优先级，使用括号来明确指定优先级。
sql
SELECT `name`, `phone` FROM `admin` WHERE `name`='admin' AND `phone`='13800000000';
# or 查询 使用括号包起来
SELECT `name`, `phone` FROM `admin` WHERE (`name`='admin' OR `phone`='13800000000');

in 条件查询 ​

  • 格式： SELECT 字段1, 字段2, ... FROM 表名 WHERE 字段 IN (值1, 值2, ...)
  • 注意事项：IN 条件查询时，值列表可以是常量列表，也可以是子查询。
sql
# in 条件查询, 查询用户名是 admin 或 test 的记录
SELECT `name`, `phone` FROM `admin` WHERE `name` IN ('admin', 'test');

排序查询 ​

  • 格式： SELECT 字段1, 字段2, ... FROM 表名 ORDER BY 字段1 [ASC|DESC], 字段2 [ASC|DESC], ...
  • 注意事项：ASC 表示升序（默认），DESC 表示降序。
sql
SELECT `name`, `phone` FROM `admin` ORDER BY `name` ASC, `phone` DESC;

分页查询 ​

  • 格式： SELECT 字段1, 字段2, ... FROM 表名 LIMIT 偏移量, 数量
  • 注意事项：偏移量从 0 开始计算。
sql
SELECT `name`, `phone` FROM `admin` LIMIT 0, 10;

模糊查询 ​

  • 格式： SELECT 字段1, 字段2, ... FROM 表名 WHERE 字段 LIKE '%keyword%'
  • 注意事项：% 表示任意字符（包括零个字符）
sql
# 模糊查询 用户名中包含 admin 的记录
SELECT `name`, `phone` FROM `admin` WHERE `name` LIKE '%admin%';

# 模糊查询 用户名以 admin 开头的记录
SELECT `name`, `phone` FROM `admin` WHERE `name` LIKE 'admin%';

# 模糊查询 用户名以 admin 结尾的记录
SELECT `name`, `phone` FROM `admin` WHERE `name` LIKE '%admin';

去重查询 ​

  • 格式： SELECT DISTINCT 字段1 FROM 表名
  • 注意事项：DISTINCT 是去重后面所有字段，而不是去重指定字段。所以DISTINCT后面尽量只有一个字段。
sql
# 去重查询, 统计每个用户名的记录数
SELECT DISTINCT `name`, count(`id`) as `count` FROM `admin`;

分组查询 ​

  • 格式： SELECT 字段1, 字段2, ... FROM 表名 GROUP BY 字段1, 字段2, ...
  • 注意事项：GROUP BY 那些字段，查询的字段必须只能包含分组字段和聚合函数。
  • 分组查询通常与聚合函数（如 COUNT, SUM, AVG, MAX, MIN）一起使用，用于对每个分组进行计算。
sql
# 分组查询, 统计每个用户名的记录数
SELECT `name`, count(`id`) as `count` FROM `admin` GROUP BY `name`;

having 子句 ​

  • 格式： SELECT 字段1, 字段2, ... FROM 表名 GROUP BY 字段1, 字段2, ... HAVING 条件
  • 注意事项：HAVING 子句用于在分组后对结果进行筛选，通常与聚合函数一起使用。
sql
# 分组查询, 统计每个用户名的记录数, 只显示记录数大于 1 的用户名
SELECT `name`, count(`id`) as `count` FROM `admin` GROUP BY `name` HAVING `count` > 1;

子查询 ​

  • 格式： SELECT 字段1, 字段2, ... FROM 表名 WHERE 字段 IN (子查询)
  • 注意事项：子查询必须返回单个列。
sql
# 子查询, 查询所有手机号在 admin 表中的记录
SELECT `name`, `phone` FROM `admin` WHERE `phone` IN (SELECT `phone` FROM `admin`);

联合查询 ​

  • 格式： SELECT 字段1, 字段2, ... FROM 表名1 UNION [ALL] SELECT 字段1, 字段2, ... FROM 表名2
  • 注意事项：
    • UNION 用于合并多个查询的结果集，默认会去重。
    • UNION ALL 会保留重复行。
    • 联合查询的字段数和数据类型必须在每个查询中匹配。

连表查询 ​

  • 类型
类型关键字作用
内连接INNER JOIN或者JOIN返回两个表中匹配的行 如果右边表没有匹配的记录, 则不返回左表的记录
左连接LEFT JOIN返回左表中的所有行，以及右表中匹配的行，不管右边是否匹配记录
右连接RIGHT JOIN返回右表中的所有行，以及左表中匹配的行, 不管左边是否匹配记录
  • 格式： SELECT 字段1, 字段2, ... FROM 表名1 连接类型 JOIN 表名2 ON 连接条件
sql
# 内连接, 常用, 只返回两个表中匹配的行
SELECT
	`admin`.`id`,
	`admin`.`name`,
	`admin`.`phone`,
	`admin`.`role_id`,
	`admin_role`.`name` as role_name
FROM
	`admin`
	JOIN `admin_role` ON `admin`.`role_id` = `admin_role`.`id`;


# 左连接, 常用, 返回左表中的所有行，以及右表中匹配的行，不管右边是否匹配记录
SELECT
	`admin`.`id`,
	`admin`.`name`,
	`admin`.`phone`,
	`admin`.`role_id`,
	`admin_role`.`name` as role_name
FROM
	`admin`
	LEFT JOIN `admin_role` ON `admin`.`role_id` = `admin_role`.`id`;


# 右连接, 不常用, 返回右表中的所有行，以及左表中匹配的行, 不管左边是否匹配记录
SELECT
	`admin`.`id`,
	`admin`.`name`,
	`admin`.`phone`,
	`admin`.`role_id`,
	`admin_role`.`name` as role_name
FROM
	`admin`
	RIGHT JOIN `admin_role` ON `admin`.`role_id` = `admin_role`.`id`;
  • 注意事项：
    • 数据表连接时，要用小表作为左表，大表作为右表。
    • 关联字段必须索引, 否则会全表扫描, 性能很差。

函数查询 ​

  • 格式： SELECT 函数名(字段) FROM 表名
  • 注意事项：函数名可以是 MySQL 提供的函数，也可以是用户自定义的函数。
sql
# 函数查询, 统计每个用户名的记录数，使用 count 函数
SELECT `name`, count(`id`) as `count` FROM `admin` GROUP BY `name`;

函数名作用示例

LENGTH(str)返回字符串字节长度（受字符集影响）LENGTH('中国') → 4（UTF-8 下）
CHAR_LENGTH(str)返回字符串字符个数CHAR_LENGTH('中国') → 2
SUBSTRING(str, pos, len)截取子串（pos 起始位置，len 长度）`SUBSTRING('abcdef', 2, 3) → bcd
TRIM(str)去除字符串首尾空格TRIM(' test ') → test
UPPER(str)转换为大写UPPER('abc') → ABC
LOWER(str)转换为小写LOWER('ABC') → abc
REPLACE(str, old, new)替换字符串中的子串REPLACE('hello', 'l', 'L') → heLLo
