HyperLogLog 基数统计 ​

  • HyperLogLog 是一种用于估计集合基数的算法，它可以在非常大的数据集上进行快速的基数统计。

优势 ​

  • 内存效率极高：无论统计的数据集有多大（哪怕是上亿级别），HyperLogLog 占用的内存几乎固定（约 12KB），远低于用集合（Set）存储所有元素的方式。
  • 统计效率极高：HyperLogLog 可以在毫秒级内完成对非常大数据集的基数统计，而集合（Set）则需要遍历所有元素才能完成统计。
  • 近似结果：误差率约为 0.81%，但对于大多数业务场景（如 UV 统计），这个精度完全可接受。

应用场景 ​

网站每日独立访客数（UV）统计 ​

go

func main() {
	ctx := context.Background()
	rds := GetRedis()

	key1 := "uv:" + time.Now().Format(time.DateOnly)
	key2 := "pv:" + time.Now().Add(time.Hour*24).Format(time.DateOnly)
	// 每日访问uv数据
	for i := 0; i < 50000; i++ {
		rds.PFAdd(ctx, key1, fmt.Sprintf("user_%d", i))
		rds.PFAdd(ctx, key2, fmt.Sprintf("user_%d", i))
	}
	// 统计uv
	uv1 := rds.PFCount(ctx, key1).Val()
	fmt.Println("uv1:", uv1)

	uv2 := rds.PFCount(ctx, key2).Val()
	fmt.Println("uv2:", uv2)
}
