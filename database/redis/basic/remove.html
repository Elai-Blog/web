淘汰策略 ​

  • 内存超过redis最大内存限制，会根据配置的淘汰策略，淘汰键值对。

配置策略 ​

ini
maxmemory 100mb # 设置最大内存限制（必须先配置）
maxmemory-policy allkeys-lru # 设置淘汰策略

策略模式 ​

不淘汰 ​

  • noeviction：默认配置，不淘汰任何键，内存满时拒绝新写入操作（返回错误）

只淘汰设置了过期时间的键 ​

  • volatile-lru：淘汰最近最少使用（LRU） 的过期键
  • volatile-lfu：淘汰最近最少频率使用（LFU）
  • volatile-ttl：淘汰剩余过期时间最短的键
  • volatile-random：随机淘汰过期键

淘汰所有键（不管是否设置过期时间） ​

  • allkeys-lru：淘汰所有键中最近最少使用的键
  • allkeys-lfu：淘汰所有键中最近最少频率使用的键（4.0+）
  • allkeys-random：随机淘汰所有键中的键

选择建议 ​

  • 缓存场景（如会话缓存）：推荐 allkeys-lru 或 allkeys-lfu，优先保留热点数据
  • 有明确过期时间的场景：使用 volatile-lru 或 volatile-ttl
  • 均匀访问场景：allkeys-random 更适合
  • 不允许数据丢失：使用 noeviction（需确保内存充足）
