浏览器驱动 ​

  • selenium 打开浏览器需要安装对应的驱动，不同的浏览器需要安装不同的驱动。

驱动安装 ​

  1. 什么是ChromeDriver：https://developer.chrome.com/docs/chromedriver?hl=zh-cn
  2. 驱动安装

    1. 确认 chrome 版本号

      • 打开 chrome 浏览器，点击菜单->帮助->关于 Google Chrome，即可查看 chrome 版本号。

    2. 驱动下载：https://googlechromelabs.github.io/chrome-for-testing

    3. 驱动安装 解压文件，将 chromedriver 放到 /usr/local/bin中

      bash
      cp chromedriver-mac-arm64/chromedriver /usr/local/bin
# 授权
cd /usr/local/bin
xattr -d com.apple.quarantine chromedriver

驱动验证 ​

bash
chromedriver --version

驱动使用 ​

python
from selenium import webdriver

driver = webdriver.Chrome()
driver.get("https://www.baidu.com")
