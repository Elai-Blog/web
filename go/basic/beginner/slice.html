切片 ​

是动态数组，长度是不固定的。

声明切片 ​

  • 格式1：var slice []type
  • 格式2：var var slice []type = make([]type, len, cap)
go
// 方式1
var slice1 []string
// 方式2
slice2 := []string{"I'm", "like", "cat"}
// 方式3
slice3 := make([]string, 0)
slice3 = append(slice3, slice2...)
// 打印结果
fmt.Println(slice1)
fmt.Println(slice2)
fmt.Println(slice3)

输出结果

[]

[I'm like cat]

[I'm like cat]

元素操作 ​

创建切片 ​

go
slice1 := []string{"I'm"}
fmt.Println(slice1)

输出结果

[I'm]

追加元素 ​

go
slice1 = append(slice1, "like")
slice1 = append(slice1, "cat")
// 追加多个元素
slice1 = append(slice1, "and", "dog")
fmt.Println(slice1)

输出结果

[I'm like cat and dog]

编辑元素 ​

go
slice1[4] = "monkey"
fmt.Println(slice1)

输出结果

[I'm like cat and monkey]

截取元素 ​

go
fmt.Println("取第一个元素：", slice1[0])
// 可以简写为arr[:2]，表示从索引0开始取，直到索引2（不包含索引2）
fmt.Println("取下标0-1的元素：", slice1[0:2])
// 表示从索引3开始取，直到数组末尾
fmt.Println("取下标3之后的元素：", slice1[3:])

输出结果

取第一个元素： I'm

取下标0-1的元素： [I'm like]

取下标3之后的元素： [and monkey]

删除元素 ​

go
// 删除索引为1的元素,从1（包含1）开始删除，到2（不包含2）
slice2 := slices.Delete(slice1, 1, 2) // 官方包 slices 删除
fmt.Println("删除：", slice2)

输出结果

[I'm cat and monkey]

查询元素 ​

  • go没有直接方法查询数组是否存在某个元素
  • 可以通过遍历数组, 比较每个元素是否等于目标元素, 来判断数组是否存在某个元素.
go
// 定义一个数组变量
sli1 := []string{"I'm", "like", "cat", "and", "monkey"}
str1 := "cat"

// 方式1
for _,value := range sli1{
	if value == str1{
		fmt.Println("数组存在元素", str1)
	}
}

// 方式2 基于 slices 包的 Index 方法
if slices.Contains(sli1, str1) {
	fmt.Println("数组存在元素", str1)
}

// 方式3 基于 sort 包的 Search方法
if sort.SearchStrings(sli1, str1) >-1 {
	fmt.Println("数组存在元素", str1)
}

空切片 ​

  • 空切片是指长度为0的切片，它的容量也为0。
go
var slice1 []string
fmt.Println(slice1, len(slice), cap(slice))
// 空切片是 nil
if slice == nil {
    fmt.Println("nil")
} else {
    fmt.Println("not nil")
}

输出结果

[] 0 0

nil

go
// 把切片按照指定的分隔符连接成一个字符串
str := strings.Join(slice, " ")
fmt.Println(str)

输出结果

I'm cat and monkey
