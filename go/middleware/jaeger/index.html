链路追踪 ​

  • 是一款开源的分布式链路追踪系统，主要用于微服务架构中的监控、故障排查和性能优化。

all-in-one ​

  • 包含所有组件
  • 数据不做持久化
  • 适用于开发环境
yaml
services:
    jaeger:
    image: jaegertracing/jaeger:2.20.0
    container_name: jaeger
    restart: always
    ports:
        - '16686:16686' # jaeger UI
        - '4317:4317' # OTLP gRPC
        - '4318:4318' # OTLP HTTP
    environment:
        - TZ=Asia/Shanghai

k8s部署 ​

  • 分别部署Otel Collector、Jaeger Collector、Jaeger Query
  • 数据必须做持久化，否则会丢失链路数据
  • 适用于生产环境
组件端口作用
Otel Collector6831/udp 14268/tcp 4317/tcp 4318/tcp收集数据，转发到Jaeger Collector
Jaeger Collector14250/tcp推送数据
Jaeger Query16686/tcpJaeger Web UI

端口放行 ​

bash
sudo firewall-cmd --permanent --add-port={4317,4318,14268,14250,16686}/tcp
# 放行UDP 6831
sudo firewall-cmd --permanent --add-port=6831/udp
# 重载防火墙规则（必须执行，否则不生效）
sudo firewall-cmd --reload
# 查看放行端口
sudo firewall-cmd --list-ports
