容器 ​

  • 运行中的镜像称为容器。

特点 ​

  • 轻量级：容器基于宿主机的操作系统内核，无需像虚拟机（VM）那样包含完整的操作系统，因此启动快、资源占用少。
  • 一致性：容器打包了所有依赖，解决了 “在我这能跑，在你那跑不了” 的环境一致性问题。
  • 隔离性：通过 Linux 内核的 Namespace 和 Cgroups 技术，实现进程、网络、文件系统等资源的隔离，确保容器间互不干扰。
  • 可移植性：容器可以在开发机、测试环境、生产服务器等任何支持 Docker 的平台上无缝迁移。
  • 可扩展性：可通过 Docker Compose 或 Kubernetes 等工具快速批量创建、管理容器，实现水平扩展。

内核选择 ​

  • 容器必须基于linux 内核系统
内核系统大小说明
ubuntu比较小更注重用户体验，适合桌面环境以及个人用户
centos比较大更倾向于企业级服务器应用，稳定性较强 但是免费版不更新维护了
debian非常小底层非常稳定,适合服务端应用

创建/启动容器 ​

  • 命令: docker run [options] [image] [command] [args]
bash
# 前台交互式终端启动容器
docker run -i -t ubuntu /bin/bash
# 后台默认执行
docker run -itd ubuntu

[options] ​

选项说明
--name为容器指定一个名称
-d后台运行容器并返回容器ID。几守护式容器（后台启动）
-i以交互模式运行容器 通常与-t 同时使用
-t为容器重新分配一个伪输入终端，通常与 -i 同时使用
-p小写p 指定端口映射 主机端口:容器端口
-P随机端口映射
-e设置环境变量
-m设置最大内存
-v设置持久化
--restart=always容器退出时自动重启（故障自愈）
--network设置网络
bash
# 启动 -itd[后台运行] --name[容器名字叫backend]
docker run -itd --name backend \
# 端口映射[宿主机]:[主机],让外部访问
-p 8100:8100 \
# 设置环境变量
-e "TZ=Asia/Shanghai" \
# 挂载日志目录：主机./logs → 容器/app/logs
-v $(pwd)/logs:/app/logs \
# 容器退出时自动重启（故障自愈）
--restart=always \
# 运行镜像
backend:v1

[image] ​

  • image：镜像名

[command] ​

  • command：容器启动后执行的命令，通常为 /bin/bash 或 /bin/sh。

[args] ​

  • args：容器启动后执行的命令参数。

列出容器 ​

bash
# 列出运行中的容器
docker ps
# 列出所有的容器（包含未运行的）
docker ps -a

删除容器 ​

bash
# 删除
docker rm [容器ID]
# 强制删除
docker rm -f [容器ID]
# 一次性删除所有容器实例：危险操作
docker rm -rf $(docker ps -a -q)
# 一次性删除所有容器实例：危险操作
docker ps -a -q | xargs docker rm

容器启动/重启/停止 ​

bash
# 启动容器
docker start [容器ID]
# 停止容器
docker stop [容器ID]
# 重启容器
docker restart [容器ID]
# 强制重启容器
docker kill [容器ID]

进入容器 ​

bash
# docker attach [容器ID/名称]
# 直接进入容器启动命令的终端，不会启动新的进行，用exit退出，会导致容器的停止
# 不推荐使用此命令
docker attach [容器ID]

# docker exec [options] [容器ID/名称] [command]
# 是在容器中打开新的终端，并且可以启动新的进程，用exit退出，不会导致容器的停止
# 推荐使用此命令
docker exec -it [容器ID] /bin/bash

查看容器日志 ​

bash
docker logs [容器ID]

查看容器内部信息 ​

bash
docker inspect [容器ID/名称]

拷贝容器文件到目的主机的路径 ​

bash
# docker cp [容器ID]:[容器内路径] [目的主机路径]
docker ps 95cf96470d5e:/usr/local/a.txt /download/a.txt

导入\导出镜像 ​

bash
# 导出镜像
docker export -o ubuntu.tar [容器ID]
# 导入镜像
docker import ubuntu.tar test/ubuntu:v2
