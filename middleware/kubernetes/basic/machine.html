静态IP ​

  • 虚拟机网络需要设置bridge模式
bash
# 安装基础工具
sudo dnf install -y vim curl wget zsh git
# 查看ip地址
ip a
# 自己的网卡名称是 enp2s0 / ens33
# 修改网卡
sudo vim /etc/sysconfig/network-scripts/ifcfg-enp2s0
  • 配置静态IP (192.168.0.150)
  • 子网掩码：255.255.255.0
  • 网关地址：192.168.0.1
  • 首选DNS：223.5.5.5
  • 备用DNS：114.114.114.114
txt
# 网卡类型：以太网
TYPE=Ethernet
# 代理方式：关闭代理
PROXY_METHOD=none
# 仅浏览器代理：关闭
BROWSER_ONLY=no
# IP获取方式：static静态IP（dhcp为自动获取）
BOOTPROTO=static
# 是否作为默认路由：开启
DEFROUTE=yes
# IPv4路由失败时是否终止网络：关闭
IPV4_FAILURE_FATAL=no
# 启用IPv6功能
IPV6INIT=yes
# IPv6自动配置开启
IPV6_AUTOCONF=yes
# IPv6默认路由开启
IPV6_DEFROUTE=yes
# IPv6异常不直接断网
IPV6_FAILURE_FATAL=no
# 网卡连接名称
NAME=enp2s0
# 系统硬件网卡名，和实际网卡一致
DEVICE=enp2s0
# 开机自动启用这块网卡 yes启用 no禁用
ONBOOT=yes
# 自定义静态IP地址
IPADDR=192.168.0.150
# 子网掩码
NETMASK=255.255.255.0
# 网关地址（路由器地址）
GATEWAY=192.168.0.1
# 首选DNS（阿里公共DNS）
DNS1=223.5.5.5
# 备用DNS（国内通用DNS）
DNS2=114.114.114.114
  • 重启网络服务
bash
# 重载配置
nmcli connection reload
# 重启网卡
nmcli connection up enp2s0
# 重启系统
sudo reboot
