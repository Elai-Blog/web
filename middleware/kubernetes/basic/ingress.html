ingress ​

  • 统一入口网关，基于 HTTP/HTTPS 域名、路径、Header 转发流量到后端 Service，仅暴露一个公网端口（80/443），实现：域名路由、路径分发、SSL 证书、限流、重定向、鉴权等七层能力。

流量转发 ​

部署 nginx-ingress-controller ​

bash
# 下载yaml到本地
curl -o ingress-controller.yaml https://raw.githubusercontent.com/kubernetes/ingress-nginx/controller-v1.15.1/deploy/static/provider/baremetal/deploy.yaml

# 【国内必做】替换镜像地址（解决registry.k8s.io无法拉取）
sed -i 's|registry.k8s.io|m.daocloud.io/registry.k8s.io|g' ingress-controller.yaml

# 执行部署
kubectl apply -f ingress-controller.yaml

ingress 规则配置 ​

yaml
apiVersion: networking.k8s.io/v1
kind: Ingress
metadata:
    name: demo-ingress
    namespace: default
    # 注解：nginx-ingress 扩展配置，核心功能都靠annotations实现
    annotations:
        # 1. 指定控制器，多ingress-controller场景区分
        kubernetes.io/ingress.class: 'nginx'
        # k8s 1.22+ 推荐替换为 spec.ingressClassName
        nginx.ingress.kubernetes.io/ssl-redirect: 'true' # 自动http跳转https
        nginx.ingress.kubernetes.io/rewrite-target: /$1 # 路径重写
        nginx.ingress.kubernetes.io/proxy-body-size: '10m' # 上传文件大小限制
        nginx.ingress.kubernetes.io/ssl-cert: 'tls-secret' # 指定证书secret
spec:
    # 绑定ingress控制器类
    ingressClassName: nginx
    # HTTPS证书配置，引用tls secret
    tls:
        - hosts:
              - blog.xxx.com
          secretName: blog-tls-secret
    # 路由规则核心
    rules:
        # 第一条域名规则
        - host: blog.xxx.com # 访问域名
          http:
              paths:
                  # 路径匹配规则
                  - path: /admin
                    pathType: Prefix # 路径匹配类型：Prefix/Exact/ImplementationSpecific
                    backend:
                        service:
                            name: blog-admin-svc # 后端service名称
                            port:
                                number: 80 # service端口
                  - path: /api
                    pathType: Prefix
                    backend:
                        service:
                            name: blog-api-svc
                            port:
                                number: 80
        # 无host，匹配所有未匹配域名（默认页面）
        - http:
              paths:
                  - path: /
                    pathType: Prefix
                    backend:
                        service:
                            name: default-404-svc
                            port:
                                number: 80

pathType ​

Prefix（前缀匹配，最常用 ​

  • /api 匹配 /api、/api/、/api/user

Exact（精确匹配，必须完全一致） ​

  • /login 仅匹配完全等于 /login，/login/ 不匹配

ImplementationSpecific（实现特定匹配，根据控制器实现） ​

  • 交给 ingress controller 自行实现，nginx-ingress 等价 Prefix

实操场景 ​

基础单域名 HTTP 路由（无 HTTPS） ​

  1. 后端 Deployment + Service
yaml
# web.yaml
apiVersion: apps/v1
kind: Deployment
metadata:
    name: web
spec:
    replicas: 2
    selector:
        matchLabels:
            app: web-rep
    template:
        metadata:
            labels:
                app: web-rep
        spec:
            containers:
                - name: nginx
                  image: nginx:alpine
                  ports:
                      - containerPort: 80
---
apiVersion: v1
kind: Service
metadata:
    name: web-svc
spec:
    selector:
        app: web-rep
    ports:
        - port: 80
          targetPort: 80
    type: ClusterIP
  1. Ingress 规则
yaml
# ingress-http.yaml
apiVersion: networking.k8s.io/v1
kind: Ingress
metadata:
    name: web1-ingress
spec:
    ingressClassName: nginx
    rules:
        - host: test.demo.com
          http:
              paths:
                  - path: /
                    pathType: Prefix
                    backend:
                        service:
                            name: web-svc
                            port:
                                number: 80

同一域名多路径分流（前端 / 后端分离） ​

  1. 访问规则
    • test.demo.com/api → 前端 web-api-svc
    • test.demo.com/admin → 后端 web-admin-svc
yaml
# ingress-multi-path.yaml
apiVersion: networking.k8s.io/v1
kind: Ingress
metadata:
    name: multi-path-ingress
    annotations:
        # 路径重写：去掉匹配的/api前缀，转发给后端根路径
        nginx.ingress.kubernetes.io/rewrite-target: /$1
spec:
    ingressClassName: nginx
    rules:
        - host: test.demo.com
          http:
              paths:
                  # 前端根路径
                  - path: /api
                    pathType: Prefix
                    backend:
                        service:
                            name: web-api-svc
                            port:
                                number: 80
                  # api路径
                  - path: /admin
                    pathType: Prefix
                    backend:
                        service:
                            name: api-admin-svc
                            port:
                                number: 8080

HTTPS 加密访问（SSL 证书 + 自动跳转 HTTP） ​

yaml
# ingress-https.yaml
apiVersion: networking.k8s.io/v1
kind: Ingress
metadata:
    name: tls-ingress
    annotations:
        nginx.ingress.kubernetes.io/ssl-redirect: 'true' # http 301跳转https
spec:
    ingressClassName: nginx
    # TLS证书绑定域名
    tls:
        - hosts:
              - blog.demo.com
          secretName: blog-tls-secret
    rules:
        - host: blog.demo.com
          http:
              paths:
                  - path: /
                    pathType: Prefix
                    backend:
                        service:
                            name: blog-svc
                            port:
                                number: 80

常用注解 ​

yaml
metadata:
    annotations:
        # 1. HTTPS强制跳转
        nginx.ingress.kubernetes.io/ssl-redirect: 'true'
        # 2. 关闭https（仅http）
        nginx.ingress.kubernetes.io/ssl-redirect: 'false'
        # 3. 路径重写正则
        nginx.ingress.kubernetes.io/rewrite-target: /$1
        # 4. 上传文件大小限制
        nginx.ingress.kubernetes.io/proxy-body-size: '20m'
        # 5. 超时时间
        nginx.ingress.kubernetes.io/proxy-connect-timeout: '60'
        nginx.ingress.kubernetes.io/proxy-read-timeout: '60'
        # 6. 开启基础认证登录
        nginx.ingress.kubernetes.io/auth-type: basic
        nginx.ingress.kubernetes.io/auth-secret: basic-auth
        nginx.ingress.kubernetes.io/auth-realm: '请输入账号密码'
        # 7. 禁止IP直接访问，必须域名
        nginx.ingress.kubernetes.io/configuration-snippet: |
            if ($host !~* demo.com ) {
              return 403;
            }
        # 8. 自定义404页面
        nginx.ingress.kubernetes.io/custom-http-errors: '404'
