网络插件 ​

  • 全称 CNI（Container Network Interface）容器网络接口插件，
  • 核心职责：给 Pod 打通网络，实现 K8s 强制网络模型。

网络模型四大标准 ​

  • 所有 Pod 可直接通信，不使用 NAT；
  • Node 与所有 Pod 互通；
  • Pod 访问 Node 自身无 NAT；
  • Pod 访问外部网络时，源 IP 保留 PodIP。

检查是否安装 ​

bash
# 查看插件二进制
ls /opt/cni/bin
# 查看网络配置
ls /etc/cni/net.d

常用cni插件 ​

插件底层技术NetworkPolicy性能运维难度适合规模特殊亮点
FlannelVXLAN/HostGW不支持中极低小集群测试极简开箱

如何选择 ​

  • Calico：中小规模集群 / 运维主导
  • Cilium：微服务重、流量大、安全细、平台化强

Calico Cni ​

工作模式 ​

模式封装方式需要放行TCP179性能适用环境
IPIP（Always）IPIP 封装IP 协议 4不需要中等虚拟机、云主机、测试集群
VXLANUDP 4789 封装UDP 4789不需要中等屏蔽 IPIP 的公有云
CrossSubnet混合同子网直连，跨子网 IPIPIP 协议 4不需要较好多网段物理机房
BGP Only无封装TCP 179必须放行最优纯物理服务器、三层机房
WireGuard加密隧道UDP51820UDP 51820不需要较好 + 加密 跨公网、安全加密需求

选择模式 ​

环境推荐模式配置要点
自建机房、可控交换机、低延迟业务BGP + RR（千节点）/FullMesh（<200 节点）vxlanMode=Never，ipipMode=Never，部署 BGP Route Reflector
阿里云 / AWS/Azure/GCP 公有云VXLAN 全覆盖vxlanMode=Always，MTU=1450，关闭 IPIP
自建多子网、防火墙封 UDP 4789IPIP CrossSubnetipipMode=CrossSubnet，vxlanMode=Never
混合云 / 多租户 SaaS 平台VXLAN多 VNI 隔离，可叠加 WireGuard 加密隧道
小规模测试 / 边缘弱网络VXLAN部署最简单，兼容性拉满

安装 ​

  • 在master节点 进行安装，他会自动同步到子节点
bash
# 下载
wget https://docs.projectcalico.org/manifests/calico.yaml
# vim  calico.yaml 修改工作模式 VXLAN
# 去掉bgp
- name: CLUSTER_TYPE
    value: "k8s"
# 改为VXLAN
- name: CALICO_IPV4POOL_VXLAN
    value: "CrossSubnet"
# 关闭IPIP
- name: CALICO_IPV4POOL_IPIP
    value: "Never"
# 运行
kubectl apply -f calico.yaml
# 检查
kubectl get pods -n kube-system -w

放行网段 ​

  • 保证节点直接可以内网互通
bash
# 查看网段
ip route | grep src
# 集群节点之间全部内网互通（你的网段192.168.0.0/24）
sudo firewall-cmd --permanent --add-source=192.168.0.0/24 --zone=trusted
# 重载生效
sudo firewall-cmd --reload

卸载 ​

bash
kubectl delete -f calico.yaml
# 所有节点执行清理残留
rm -rf /etc/cni/net.d/\*
rm -rf /opt/cni/bin/calico\*
