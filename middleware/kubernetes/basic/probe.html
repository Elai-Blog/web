探针 ​

  • K8s 探针是 kubelet 用来检测容器运行状态的机制，根据探测结果决定是否重启、转发流量、调度 Pod。

startupProbe 启动探针 ​

  • 专门给启动极慢的应用，避免刚启动就被 liveness 误杀。
  • 逻辑：startupProbe 成功前，liveness/readiness 全部禁用；
  • 探测成功 → 切换到 liveness/readiness 正常工作；
  • 持续失败 → 重启容器。
  • 适用：Java、SpringBoot、大数据组件等启动耗时几十秒 / 分钟的服务。

readinessProbe 就绪探针 ​

  • 判断容器是否就绪接收业务流量。
  • 探测失败：Pod 状态置为 NotReady，Service 从 Endpoints 移除，不再转发流量。
  • 探测成功：Pod 变为 Ready，加入 Service 负载均衡。
  • 典型场景：应用启动慢、数据库连接未完成、初始化任务未结束。

livenessProbe 存活探针 ​

  • 判断容器是否卡死、崩溃、无响应。
  • 探测失败 → kubelet 杀死容器，根据 restartPolicy 重启 Pod。
  • 典型场景：程序死锁、进程挂掉但容器没退出。

探测方式 ​

exec 命令探测 ​

yaml
livenessProbe:
    exec:
        command: ['cat', '/tmp/health']
    initialDelaySeconds: 5
    periodSeconds: 10

httpGet 探测 ​

yaml
livenessProbe:
    httpGet:
        path: /
        port: 80
    initialDelaySeconds: 5
    periodSeconds: 10

tcpSocket 探测 ​

yaml
livenessProbe:
    tcpSocket:
        port: 80
    initialDelaySeconds: 5
    periodSeconds: 10

配置参数 ​

参数含义默认值
initialDelaySeconds容器启动后首次探测等待时间0
periodSeconds探测间隔10s
timeoutSeconds单次探测超时时间1s
failureThreshold连续失败多少次判定异常3 次
successThreshold连续成功多少次判定正常1 次

完整案例 ​

yaml
apiVersion: apps/v1
kind: Deployment
metadata:
    name: demo-app
spec:
    replicas: 1
    selector:
        matchLabels:
            app: demo
    template:
        metadata:
            labels:
                app: demo
        spec:
            containers:
                - name: demo
                  image: nginx
                  ports:
                      - containerPort: 80
                  # 启动探针：给慢启动应用
                  startupProbe:
                      httpGet:
                          path: /api/health
                          port: 80
                      # 容器启动后首次探测等待时间
                      initialDelaySeconds: 3
                      # 探测间隔
                      periodSeconds: 15
                      # 单次探测超时时间
                      timeoutSeconds: 5
                      # 连续失败多少次判定异常
                      failureThreshold: 12
                      # 连续成功多少次判定正常
                      successThreshold: 1
                  # 就绪探针：就绪才接入流量
                  readinessProbe:
                      httpGet:
                          path: /api/health
                          port: 80
                      # 容器启动后首次探测等待时间
                      initialDelaySeconds: 20
                      # 探测间隔
                      periodSeconds: 20
                      # 单次探测超时时间
                      timeoutSeconds: 3
                      # 连续失败多少次判定异常
                      failureThreshold: 3
                      # 连续成功多少次判定正常
                      successThreshold: 1
                  # 存活探针：卡死自动重启
                  livenessProbe:
                      httpGet:
                          path: /api/health
                          port: 80
                      # 容器启动后首次探测等待时间
                      initialDelaySeconds: 30
                      # 探测间隔
                      periodSeconds: 30
                      # 单次探测超时时间
                      timeoutSeconds: 3
                      # 连续失败多少次判定异常
                      failureThreshold: 3
                      # 连续成功多少次判定正常
                      successThreshold: 1
