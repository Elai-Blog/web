私有仓库 ​

  • harbor 是一款比较通用的私有化部署的镜像仓库
  • 口语叫法：哈(har)伯(bor)

安装 ​

前置要求 ​

  • CPU：2 核 +（推荐 4 核）
  • 内存：4GB+（推荐 8GB）
  • 磁盘：40GB+（镜像多就 100GB+）Harbor
  • Docker
  • Docker Compose
bash
# 安装docker
curl -fsSL https://get.docker.com | bash
systemctl enable docker
systemctl start docker
docker -v
# 安装docker-compose
# @see https://github.com/docker/compose/releases 找到最新版本
# 我是mac 环境选aarch64
curl -L https://github.com/docker/compose/releases/download/v5.1.4/docker-compose-linux-aarch64 -o /usr/local/bin/docker-compose
chmod +x /usr/local/bin/docker-compose
docker-compose -v

下载harbor ​

bash
# @see https://github.com/goharbor/harbor/releases 找到最新版本
wget https://github.com/goharbor/harbor/releases/download/v2.14.4/harbor-offline-installer-v2.14.4.tgz
tar -zxvf harbor-offline-installer-v2.14.4.tgz

配置 harbor.yml ​

bash
# 返回harbor目录
cd harbor
cp harbor.yml.tmpl harbor.yml
vim harbor.yml
yaml
# 1. 主机名（写服务器 IP 或域名）
# 外网ip
hostname: x.x.x.x

# 2. HTTP 端口（默认80，可改）,尽量改其他的，防止冲突
http:
    port: 8011
# 3. 关键：设置外部访问URL（你的外网域名）
external_url: https://harbor.elai.team

# 4. 禁用HTTPS，参考下面的图

# 5. 管理员密码（必须改，改复杂点的密码）
harbor_admin_password: wpGzDLbbjAyn2tsQ
# 6. 数据存储位置（默认 /data，可改大磁盘）
data_volume: /data

部署nginx+https ​

  • 配置nginx
ini
server {
    listen 443 ssl;
    # 配置域名
    server_name harbor.elai.team;
    # 配置证书
    ssl_certificate /etc/nginx/certs/harbor.crt;
    ssl_certificate_key /etc/nginx/certs/harbor.key;

    location / {
        proxy_pass http://127.0.0.1:8011;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;

        # 关键：Harbor 上传大镜像时的超时配置
        proxy_connect_timeout 600;
        proxy_send_timeout 600;
        proxy_read_timeout 600;
        client_max_body_size 0; # 取消文件大小限制
    }
}

使用案例 ​

  • 编辑Dockerfile.Backend-Api
dockerfile
# 第一步：打包
# 设置go版本作为基础镜像,最好为自己项目的go版本号
FROM golang:1.26-alpine AS builder
# 维护者信息
LABEL author=elai

# 设置代理
ENV GO111MODULE=on
ENV GOPROXY=https://goproxy.cn,direct
# 禁用cgo
ENV CGO_ENABLED=0
# 设置服务器环境
ENV GOOS=linux
# 设置打包架构amd64/arm64
ENV GOARCH=amd64

# 设置工作区
WORKDIR /build
# 依赖文件
COPY go.mod go.sum ./
RUN go mod tidy
# 复制代码到容器
COPY . .

# 进行打包
RUN go build -ldflags="-s -w" -o /build/api/backend /build/api/backend/backend.go

# 第二步：运行镜像
# alpine它是一个空的镜像，在临时基础镜像上运行的应用程序只能访问内核
FROM alpine
# 设置镜像名
LABEL name=backend

# 安装时区数据 + 设置时区（彻底解决时区问题）
RUN apk add --no-cache tzdata
ENV TZ=Asia/Shanghai

# 配置工作目录
WORKDIR /app
# 复制包到容器
COPY --from=builder /build/api/backend/backend /app/backend
# 复制配置文件到容器
COPY --from=builder /build/api/backend/etc /app/etc

EXPOSE 8100
# 运行服务
CMD ["./backend", "-f", "etc/backend-api-docker.yaml"]
  • 构建镜像
bash
docker build -t elai/backend-api:latest -f Dockerfile.Backend-Api .
# 查看镜像
docker images
  • 关联自己仓库
bash
docker tag elai/backend-api:latest  harbor.elai.team/base/backend-api:v1
  • 推送仓库
bash
docker login harbor.elai.team
# 输入自己的账号密码
# 然后推送
docker push harbor.elai.team/base/backend-api:v1
  • 拉取仓库
bash
docker run -itd harbor.elai.team/base/backend-api:v1
