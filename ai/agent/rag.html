RAG ​

RAG（Retrieval-Augmented Generation，检索增强生成）是一种结合 信息检索 （Retrieval）与 文本 生成 （Generation）的技术，旨在提升大语言模型在回答专业问题时的 准确性 和 可靠性 。

大模型的局限 ​

知识滞后 ​

LLM 训练数据有截止日期 ，无法及时反映 最新的信息 或动态变化。比如：难以应对诸如“请推荐当前 热门影片”等时间敏感性问题。

知识缺失 ​

大型语言模型（LLM）的训练依赖于网络上 海量公开的静态数据 ，而某些 特定领域 （如企业内部资料、专有技术文档等）或 你的私有数据 是缺乏的，导致模型回复时生成不准确甚至虚构的回复。

幻觉 ​

LLM 在生成回答时，可能会 “胡言乱语” ，这种现象称之为 LLM 的“幻觉”。“幻觉”可以体现为错误陈述、编造事实、错误的复杂推理或者复杂语境下理解能力不足等。

工作流 ​

RAG优缺点 ​

RAG的优点 ​

  • 相比提示词工程，RAG有 更丰富的上下文和数据样本 ，可以不需要用户提供过多的背景描述，就能生成比较符合用户预期的答案。
  • 相比于模型微调，RAG可以提升问答内容的 时效性 和 可靠性
  • 在一定程度上保护了业务数据的 隐私性 。

RAG的缺点 ​

  • 由于每次问答都涉及外部系统数据检索，因此RAG的 响应时延 相对较高。
  • 引用的外部知识数据会 消耗大量的模型Token 资源。

向量数据库 ​

  • ChromaDB: 本地调试、demo，禁止正式环境使用
  • Qdrant: 适合几十万向量
  • Milvus：适合百万、千万级向量
  • Neo4j：知识图谱、GraphRAG
  • NebulaGraph: 企业级超大知识图谱，一般小 RAG 项目不用考虑

ChromaDB 案例 ​

向量操作 ​

python
from chromadb.api.models.Collection import Collection
from chromadb.utils import embedding_functions
import chromadb
from app.config import BASE_DIR

KB_DIR = BASE_DIR / "data" / "kb"  # 知识库目录
CHROMA_DIR = BASE_DIR / "data" / "chroma"  # chroma 数据库目录

# 获取chromadb
def get_collection() -> Collection:
	"""向量库客户端"""
	KB_DIR.mkdir(parents=True, exist_ok=True)  # 创建知识库目录
	CHROMA_DIR.mkdir(parents=True, exist_ok=True)  # 创建 chroma 数据库目录
	# 创建持久化客户端 数据存放CHROMA_DIR中
	client = chromadb.PersistentClient(path=str(CHROMA_DIR))
	# 创建向量库
	ef = embedding_functions.SentenceTransformerEmbeddingFunction(
		model_name="BAAI/bge-small-zh-v1.5"
	)
	coll = client.get_or_create_collection(
		name="lab_kb",
		embedding_function=ef,
	)
	return coll

# 把数据更新到chromadb
def update_collection():
	"""更新向量库"""
	ids = []
	docs = []
	metas = []
	for path in sorted(KB_DIR.glob("*.md")):
		# 读取数据库
		text = path.read_text(encoding="UTF-8").strip()
		if not text:
			continue
		docs.append(text)
		ids.append(path.stem)
		metas.append({"source": path.name})

	if docs:
		coll = get_collection()
		coll.upsert(ids=ids, documents=docs, metadatas=metas)
# 查询rag
def rag_search(query: str):
	"""根据关键字去检索向量库"""
	col = get_collection()
	if col.count() == 0:
		return ""

	res = col.query(
		query_texts=[query],
		n_results=5,  # 检索前1条
		include=["documents", "metadatas", "distances"]
	)
    # 查询数据解析
	docs = (res.get("documents") or [[]])[0]
	metas = (res.get("metadatas") or [[]])[0]
	distances = (res.get("distances") or [[]])[0]

    # 判断查询数据优先级，过滤低级的回答
	context_list = []
	for doc, meta, dist in zip(docs, metas, distances):
		if dist > 0.5:
			# 评分越小越正确，大于0.5 不予考虑
			continue
		context_list.append({
			"text": doc,
			"source": meta["source"],
			"distance": round(dist, 4)
		})
	context_str = "\n".join([item["text"] for item in context_list[:2]])
	return context_str

llm 调用 ​

python
# 系统提示词
system_prompt = SYSTEM_PROMPT
# 取出用户最新的一条提问内容
question = "用户最新的提条提问内容"
# 查询rag
knowledge = rag_search(query=question)
if knowledge:
    # 把查询的数据结合system_prompt
    system_prompt += "\n\n以下是检索到的资料：\n" + knowledge

client = get_client()
try:
    res = client.chat.completions.create(
        model=settings.llm_model,
        messages=[
            ChatMessage(role="assistant", content=SYSTEM_PROMPT).model_dump(),
            *history,
        ],

    )
    content = res.choices[0].message.content
    print(content)
    if not content.strip():
        raise BusinessException(message="大模型没有返回内容")
    return content
except Exception:
    raise BusinessException(message="大模型调用失败，请稍后重试")
