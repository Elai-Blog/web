任务 ​

  • 用来处理耗时任务：发送短信、推送消息、同步第三方数据、邮件、大数据统计等。
  • 中文文档：https://learnku.com/docs/laravel/12.x/jobs/16974

环境准备 ​

txt
# 生产用 redis / database，不要 sync
QUEUE_CONNECTION=redis

创建任务 ​

bash
php artisan make:job SendSmsJob
php
<?php

namespace App\Jobs;

use Illuminate\Contracts\Queue\ShouldQueue;
use Illuminate\Foundation\Queue\Queueable;
use Illuminate\Support\Facades\Log;

class SendSmsJob implements ShouldQueue
{
    // 提供队列相关功能：延迟、连接、队列名等
    use Queueable;

    // 最大尝试次数
    public $tries = 3;

    // 单次超时秒数（任务运行超过时间直接终止）
    public $timeout = 10;

    // 重试间隔（秒），也可以传数组实现阶梯重试 [5,10,30]
    public $backoff = 5;

    // 指定队列名称，方便优先级调度
    public $queue = "sms";

    // 指定队列连接（多redis场景）
    public $connection = "redis";

    // 任务接收参数（尽量使用Eloquent模型/简单类型）
    public function __construct(
        public string $phone,
        public string $content
    )
    {
    }

    /**
     * 任务执行入口
     */
    public function handle(): void
    {
        Log::info("开始发送短信", [
            'phone' => $this->phone,
            'content' => $this->content
        ]);

        // 模拟调用第三方短信API
        // throw new \RuntimeException("网关异常"); // 测试失败重试
    }

    /**
     * 任务多次失败最终执行回调（可选）
     */
    public function failed(\Throwable $exception): void
    {
        Log::error("短信任务彻底失败", [
            'phone' => $this->phone,
            'err' => $exception->getMessage()
        ]);
    }
}

分发任务 ​

php
use App\Jobs\SendSmsJob;

// 1. 立即推送队列
SendSmsJob::dispatch('13800138000', '您下单成功！');

// 2. 延迟执行（30秒后运行）
SendSmsJob::dispatch('13800138000', '您下单成功！')->delay(30);

// 3. 指定队列名称分发
SendSmsJob::dispatch('13800138000', '您下单成功！')->onQueue('sms');

// 4. 同步执行（不走队列，原地运行，调试用）
SendSmsJob::dispatchSync('13800138000', '您下单成功！');

消费任务 ​

bash
# 基础消费
php artisan queue:work

# 消费指定队列（优先sms，其次stat）
php artisan queue:work --queue=sms,stat

# 生产守护模式（推荐，代码修改需要重启进程）
php artisan queue:work --daemon --queue=sms,stat

# 只处理一次任务就退出（定时任务场景）
php artisan queue:work --once

失败任务管理 ​

bash
# 查看失败任务
php artisan queue:failed

# 重试指定ID任务
php artisan queue:retry 任务ID

# 重试所有失败任务
php artisan queue:retry all

# 删除失败任务
php artisan queue:forget 任务ID

# 清空所有失败任务
php artisan queue:flush
