钩子 husky ​

  • git 提交之前的验证钩子
  • 可以在 commit 之前，执行自定义操作，例如：代码格式化

安装 ​

  • 安装
bash
pnpm install -D husky
  • 初始化
bash
npx husky init
  • 在 package.json 中加入脚本
json
"scripts": {
    "prepare": "husky",
}

lint-staged ​

  • 只对【git 暂存区】的文件执行 lint / 格式化，而不是扫描整个项目

安装 ​

bash
pnpm install -D lint-staged

使用 ​

  • 修改 .husky/pre-commit
sh
npx lint-staged

配置 ​

  • 在项目目录下创建 lint-staged-config.js,内容如下
js
export default {
	'*.{js,jsx,ts,tsx,vue}': ['eslint --fix'],
	'*.{js,jsx,ts,tsx,vue,json,md,css,scss}': ['prettier --write'],
};

commit-msg ​

  • 验证提交代码前的commit信息

生成 ​

bash
echo "npx --no -- commitlint --edit \$1" > .husky/commit-msg
